Parallel Circuit Rule

Every branch receives the same voltage. Current divides between branches.

1 / R Total = 1 / R1 + 1 / R2 + 1 / R3

Total current equals the sum of all branch currents.

🔬 Series vs Parallel

Series

Same current through every component.

Voltage divides across resistors.

One path for current.

Parallel

Same voltage across every branch.

Current divides between branches.

Multiple paths for current.
